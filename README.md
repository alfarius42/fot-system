# FOT System — планирование смен и учёт ФОТ (производство)

Монорепозиторий: **демо-прототип (React)** + **project-docs** (ТЗ, оценка).

Лид на YouDo не сросся (2026-09) — делаем **интерактивный прототип для кейса** в портфолио.

| Папка | Назначение | Ветка |
|-------|------------|-------|
| `prototype/frontend/` | Демо UI (5 экранов, mock data) | `develop` → `main` |
| `project-docs/` | ТЗ, спеки, оценка, case study | `develop` |

## Быстрый старт

```bash
git clone https://github.com/alfarius42/fot-system.git
git checkout develop

cd prototype/frontend
npm install
npm run dev
```

Документация: [`project-docs/DOCUMENTATION_INDEX.md`](project-docs/DOCUMENTATION_INDEX.md)

- `main` — релиз демо (деплой на Vercel/Netlify)
