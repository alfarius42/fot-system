# Бенчмарки скорости — для оценки FOT System

Источник: проект [Areda-pylesosov](file:///C:/LK-httpsarenda-pylesosa.ru) (ЛК + admin, PHP, ~50 dev-ч в смете).

## 1. Референсный проект (факт)

| Метрика | Значение |
|---------|----------|
| Scope | ЛК + admin, auth, CRUD, 152-ФЗ, оплата, email, интеграции |
| План dev-ч (смета) | ~51 ч |
| Факт active dev (git heuristic) | ~38–51 ч |
| Календарь коммитов | 13 дней, 10 активных |
| Строк кода LK-v2 | ~100k insertions |

**Вывод:** смета ~51 dev-ч для среднего веб-LK **реалистична**; фактическое исполнение с AI-assisted dev — **~0.9× от сметы** по чистому dev.

## 2. Формула оценки (шаблон сметы)

| Роль | ₽/ч | Примечание |
|------|-----|------------|
| Аналитик | 1 000 | ТЗ, модель данных, уточнения |
| Дизайн | 1 000 | UI дашборда и форм *(если нужен)* |
| Dev | 1 500 | Разработка |
| QA / handover | 1 500 | Тесты, инструкция, деплой |

**Календарь:**

- `календарные_часы = dev_ч × 1.5` (буфер на контекст, ревью, мелочи)
- `календарные_дни = календарные_часы / 8`
- **+20% буфер** на риски интеграции и уточнений ТЗ

**Налог самозанятости:** +6% к итогу (как в смете Areda).

## 3. Декомпозиция FOT System (черновик dev-ч)

Оценка **до ответов на BRIEF.md** — диапазон. Уточнить после ответов.

| Блок | ID | Описание | Dev ч (min–max) |
|------|-----|----------|-----------------|
| B0 | AN-01 | Аналитика, модель данных, финал spec | 3–4 *(аналитик)* |
| B1 | INF-01 | Scaffold, auth, роли, хостинг | 4–6 |
| B2 | REF-01 | Справочники: должности, категории, сотрудники, ставки | 4–6 |
| B3 | SCH-01 | График на месяц (UI + расчёт планового ФОТ) | 10–16 |
| B4 | OPS-01 | Оперативка: завтра, явка, доп. вызов, план vs факт | 6–10 |
| B5 | DSH-01 | Дашборд: KPI, фильтры, графики | 8–12 |
| B6 | INP-01 | Ежедневный ввод (выручка, продукция, явка) | 4–6 |
| B7 | CALC-01 | Расчёты: ФОТ план/факт, % от выручки, аутсорс A/B | 6–10 |
| B8 | CONC-01 | Concurrent edit 3–5 users (optimistic lock / realtime) | 2–4 |
| B9 | DOC-01 | Инструкция + деплой + smoke | 2–3 |
| B10 | DS-01 | UI/UX дашборда и форм *(опционально)* | 0–4 *(дизайн)* |

**Итого dev (черновик):** 46–73 ч → **~55 ч mid**

**Календарь (mid):** 55 × 1.5 = 82.5 ч → **~10 раб. дней** + 20% буфер → **~12 раб. дней**

**Сравнение с ЛК:** FOT проще по интеграциям (нет оплаты, 152-ФЗ, webhook), но **сложнее доменная логика** (4 категории, график, KPI). Ожидаемый объём **~80–90% от ЛК MVP** по dev-ч.

## 4. Риски, влияющие на оценку

| Риск | Δ к оценке |
|------|------------|
| >5 участков или сложная номенклатура | +4–8 dev-ч |
| Импорт истории из Excel | +3–6 dev-ч |
| Жёсткие роли / audit log | +2–4 dev-ч |
| Realtime sync (websockets) вместо lock | +4–6 dev-ч |
| Кастомный дизайн «как BI-система» | +4–8 ч (дизайн + dev) |
