# Календарный план

**Статус:** черновик. Финализировать после ответов на `QUESTIONS.md` и файла `estimate-fot.xlsx`.

База: 8 ч/день · старт после подписания договора · **без приёмки** в dev-оценке.

## Черновик (mid ~55 dev-ч → ~12 раб. дней с буфером)

| День | Фокус | Milestone |
|------|-------|-----------|
| Д1 | Финал spec, модель данных, scaffold + auth | Spec + вход |
| Д2–Д3 | Справочники (должности, сотрудники, ставки, категории) | CRUD готов |
| Д4–Д6 | График на месяц + план производства + расчёт планового ФОТ | Планирование |
| Д7–Д8 | Оперативка: завтра, явка, доп. вызов | День в день |
| Д9–Д10 | Дашборд + фильтры + KPI | Аналитика |
| Д11 | Ежедневный ввод + concurrent users | Ввод данных |
| Д12 | Инструкция, деплой, smoke | Delivery |
| Д13–Д14 | Буфер 20% | — |

**M1 (~конец нед 1):** справочники + график  
**M2 (~конец нед 2):** дашборд + оперативка + деплой

Приёмка заказчика — **уточнить**, входит ли в оценку.
