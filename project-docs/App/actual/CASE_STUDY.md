# Case Study — FOT System (демо-прототип)

**Статус:** лид не сросся (YouDo, 2026-09). Прототип — для портфолио и скринов.

## Контекст

Производство готовой еды: планирование смен, 4 категории оплаты персонала (свой нал/офиц, аутсорс А и Б), контроль ФОТ как % от выручки (цель ≤ 15%).

Заказчик вёл учёт в таблицах; нужно единое веб-приложение с дашбордом и оперативкой «за день до».

## Задача (из ТЗ)

1. Справочники: должности, сотрудники, ставки, категории.
2. График на месяц с плановым ФОТ.
3. Оперативная корректировка: завтра, явка, доп. вызов.
4. Дашборд KPI + ежедневный ввод выручки и производства.

## Решение (прототип)

Frontend-only демо на mock-данных:

- 5 экранов с навигацией
- KPI и графики на Recharts
- Матрица графика и таблицы явки
- Русский UI, реалистичные фикстуры (март 2026)

Полный MVP (backend, auth, concurrent edit) оценивался в ~55 dev-ч по бенчмарку [Areda-pylesosov](https://github.com/alfarius42/Areda-pylesosov).

## Скриншоты для кейса

1. Дашборд — ФОТ план/факт, % от выручки
2. График — сотрудник × день
3. Завтра — нехватка + доп. вызов
4. Ежедневный ввод
5. Справочники — 4 категории сотрудников
